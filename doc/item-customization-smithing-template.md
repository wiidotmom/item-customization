# Item Customization

**Item customization** is a type of [smithing template](https://minecraft.wiki/w/Smithing_Template) used in [smithing tables](https://minecraft.wiki/w/Smithing_Table) to customize [items](https://minecraft.wiki/w/Item). It is consumed when used, but can be duplicated using an existing template, [terracotta](https://minecraft.wiki/w/Terracotta), and [gold ingots](https://minecraft.wiki/w/Gold_Ingot).

## Obtaining

Item Customization [Smithing Templates](https://minecraft.wiki/w/Smithing_Template) are found in [trail ruins](https://minecraft.wiki/w/Trail_Ruins). Once obtained, it can be duplicated using the crafting recipe below.

This item can only be extracted from [suspicious gravel](https://minecraft.wiki/w/Suspicious_Gravel) using a [brush](https://minecraft.wiki/w/Brush).


## Usage

### Configuring

Item customization smithing templates can be configured to specify which customizations to apply. Using opens the Item Customization screen. A preview item shows the customizations that will be applied. The cost in [resin clump(s)](https://minecraft.wiki/w/Resin_Clump) is displayed below the preview.
